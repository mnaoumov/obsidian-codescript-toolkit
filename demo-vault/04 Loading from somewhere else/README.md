# Loading from somewhere else

A module does not have to be a file in your vault at all. `require()` also accepts URLs — remote, local, and the `app://` ones Obsidian hands you — so you can run code you never installed.

| Note                                        | What it covers                                         |
| ------------------------------------------- | ------------------------------------------------------ |
| [27 URLs](<./27 URLs.md>)                   | Run code straight from an HTTPS URL, nothing installed |
| [28 File URLs](<./28 File URLs.md>)         | Reach a file outside the vault, including on Windows   |
| [29 Resource URLs](<./29 Resource URLs.md>) | Require an `app://` URL Obsidian handed you            |
