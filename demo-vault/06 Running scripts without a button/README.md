# Running scripts without a button

A code button is convenient while you are reading, but it needs a note open and a click. These notes turn a script into something you can trigger the way you trigger anything else in Obsidian — a command, a hotkey, a startup hook, or a URL from outside the app.

| Note                                                | What it covers                                                     |
| --------------------------------------------------- | ------------------------------------------------------------------ |
| [37 Invocable scripts](<./37 Invocable scripts.md>) | Export `invoke()` and your script becomes an Obsidian command      |
| [38 Invoke scripts](<./38 Invoke scripts.md>)       | Point at a folder; every script in it gets a command automatically |
| [39 Startup script](<./39 Startup script.md>)       | One script that runs every time Obsidian loads                     |
| [40 Hotkeys](<./40 Hotkeys.md>)                     | Bind a script to a key, like any other command                     |
| [41 Protocol URLs](<./41 Protocol URLs.md>)         | Trigger a script from outside Obsidian, via `obsidian://`          |
